# Browser Memory Agent

AI-powered browser memory agent that preserves and restores your cognitive workflow across sessions.

Memora observes browser activity, builds semantic memory from your browsing patterns, and lets you conversationally retrieve or restore past work contexts like:

- "Restore my LangGraph research from yesterday"
- "What did I study about Python last night?"
- "Open all tabs related to startup ideas"

Built with LangGraph, embeddings, and semantic memory retrieval.
